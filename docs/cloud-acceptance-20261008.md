## 修正

1. 承認済み6項目の表示改修をそのまま起点とした。駒モデル、原画、トップの無加工サンプルを再制作していない。
2. Crownの非常に短い画面と狭い幅で進行表示がはみ出し、操作領域が縮みすぎる問題を修正。必要な縦スクロール、折り返し、パネル最小高さを確保した。
3. 新規登録はメール＋アカウント名＋パスワード。登録ルーターから新しいservice-only RPCへ連絡メールを渡す。アカウント名＋パスワードで実際のログインまで進む。名前の前後空白を揃え、認証失敗とサービス障害を区別し、登録成功後のログイン障害では再登録を促さずログイン再試行に戻す。
4. 従来の登録APIと既存bcryptパスワードを維持。メールは未確認の非公開連絡情報であり、認証・復旧権限を与えない。新テーブルはRLS・権限拒否・削除cascade、登録は原子的処理。新規migrationは未公開・未適用。公開時にはmigrationとサーバー/クライアントの整合が必要。
5. この保存内容を12言語のプライバシー表示に追記した。他の認証、セッション取消、復旧、制限アカウント、課金権限は変更していない。
6. 解説QUBEの実ブラウザfixtureは新しいローカルSVGだけを許可するよう追随させた。外部通信遮断は維持した。

旧クライアントはメールを持たない2フィールド登録が継続可能。既存アカウントにメール追加を強制しない。既存ログイン機構はソース・隔離DBで動作した。登録のメール欠落、前後空白、汎用エラーは修正したが、現在の本番障害原因を本番環境で確定したとは主張しない。

## 性能・未確認・失敗の扱い

実行はクラウドChromium153 / ANGLE Vulkan SwiftShader（ソフトウェアGPU）。最終演出計測は390×844で32区間、平均約10.38fps、中央値33.3ms、p95 50ms。1280×720では13区間、平均約4.22fps、中央値16.7ms、p95約2566.6ms。短いrAF測定で起動・シェーダー準備・クラウド競合を含み、実GPU/実機の性能とは扱わない。60fps目標は未達の測定であり、機能チェック成功は性能合格を意味しない。追加リデザインや品質を落とす変更で数値を隠さない。

HTMLAudioElementの実ファイル再生・currentTime進行は確認したが、headlessクラウドで実際に聞くことはできない。モバイル実機性能・GPU負荷/メモリ・スピーカーの音量/音質・ネイティブズーム/文字拡大・本番schemaや実アカウントの登録は未実施。

途中の失敗は記録して修正/再確認した: Playwrightブラウザ取得の不完全DL（別の正式配布バイナリをクラウドに導入）、日本語フォント欠落（Noto CJK導入後再撮影）、新QUBE画像を旧fixtureが遮断（限定許可後成功）、生成fixture一時TSXによる型チェック失敗（一時ファイルを別場所に保全後成功）、公開HTMLの別プロセス接続失敗（同一プロセスのloopbackサーバーで8ページ成功）。旧基準の写真・動画やトップのサンプル画像を今回の画面証拠に代用していない。

スクリーンショット・動画・JSONは納品ZIPに保存する。動画には複数回の検証録画が含まれる。今回の変更patch、各fixture、最終treeとSHA256一覧により未公開状態を再現可能。
