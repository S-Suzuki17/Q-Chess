# Web / Android 共通ソースの境界

2026-09-24 ユーザー指定。ゲームの変更は同じブランチ・同じソースから両方へビルドする。

| 対象 | 含める機能 |
| --- | --- |
| Web のみ | QUBEコーナー、今回追加・改訂した遊び方／プライバシー等の公開説明、AdSense配置対応 |
| Android のみ | AdMobネイティブ連携、Google Play事前登録特典の受け取り・復元UI |
| 共通 | ルール、CPU／オンライン対局、クラウン・サーキット、報酬・BGM、盤・駒・装飾、通常UI、不具合修正 |

- Web は通常ビルド。Android は `scripts/release/build-android-web.cjs` が `NEXT_PUBLIC_APP_TARGET=android` を明示する。実行時のCapacitor判定も併用する。
- Androidから公開プライバシーポリシー・問い合わせへアクセスする導線は残す。説明ページは外部Webを開き、QUBEはアプリ内表示しない。
- 事前登録特典の配布、AdMob本番広告、回数制限、対局間広告はリリーススクリプトでOFFに固定。サーバーだけ有効化されてもクライアントから勝手に請求しない。
- 将来の獲得済み特典のサーバー検証・共通装備処理は共通コード。Google Playの受領操作はAndroidでしか行えない。
- Web公開とAAB生成は別の配布手順であり、Web公開だけではインストール済みアプリは更新されない。
- 古いAndroidフォルダーからゲームコードを戻してビルドしない。両対象の回帰テスト・同梱アセット照合結果とソースコミットをリリース記録へ残す。
