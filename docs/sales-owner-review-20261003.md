# Q-Gambit Web会員・無料券の規約改定案（公開前確認）

この原稿は未発効です。発効日は検証完了後の実際の公開日とし、それまで購入・回数制限はOFFです。現行の規約全体のうち、料金・報酬と退会時の扱いを次の内容へ改定します。他の条項と法令上の消費者の権利は維持します。

## 無料の対局・ログイン報酬

- アカウントごとにUTC日付で開始したランク戦は1日3試合まで無料。以降は対局券1枚を使用します。
- 待機、マッチ不成立、開始前キャンセルでは消費しません。開始後の障害等で返還対象となった券は、通常の保有上限によって失われない返還分として別に管理します。
- 連続ログイン1〜7日目の対局券は1・1・1・2・2・2・3枚、CPU練習ヒント券は2・2・3・3・4・4・5枚。7日目以降は最大段階を維持し、UTC日付で1日逃すと1日目へ戻ります。
- 無料券の保有上限は各20枚。空き枚数の範囲で付与します。本人確認と対象規約への同意後に受け取れます。
- ヒント券はCPU練習専用です。オンライン戦・ランク戦・クラウン・サーキットでは使用しません。

## Q-Gambit Plus（Web会員）

- 月額総額USD 2.99。購入日から1か月ごとに、解約するまで自動更新されます。初回購入時と毎月の更新時に請求します。
- 決済成功とサーバー確認後に特典を提供します。有効期間中に毎日ログインすると、対局券3枚・CPU練習ヒント券3枚を受け取れます。
- 会員券は無料券とは別枠で各60枚まで。上限を超える分は付与されず、ログインしなかった日の分はまとめて受け取れません。
- 通常の解約はWebの請求管理から次回更新を停止します。支払済み期間の末日まで特典を利用でき、通常解約の日割り返金はありません。適用法令上の権利は制限しません。
- 会員終了・返金・決済取消で未使用の会員券は失効し、再加入へ持ち越しません。無料券は影響を受けません。
- 券は譲渡・換金できません。通信費、カード会社の為替換算・手数料は利用者負担となる場合があります。
- Androidでは既に購入した特典の利用のみを提供し、購入・外部決済への誘導は表示しません。広告は引き続き停止します。

## 退会と決済情報

- Web会員のあるアカウントは、購読解約を確認してからアカウント削除を完了します。削除後は会員特典と未使用券を利用できません。
- Stripeは決済に必要な情報を処理し、Q-Gambitのサーバーは購読状態・決済通知・付与/消費の記録を処理します。カード番号をQ-Gambitで保存しません。
- 削除後の遅延通知でアカウントや特典が再作成されないよう、必要最小限の決済処理識別子を分離して保持します。法令・決済事業者側で必要な保存を即時削除できるとは約束しません。
