# Android広告の修正と公開状況

WebのAdSenseとAndroidのAdMobは別に判定する。2026-10-23にWebの再審査が受け付けられ、審査待ちとなった。Web広告とH5 Games Adsは引き続き無効。AdSense以外のサービスへの申し込み・SDK追加はしていない。

## Androidの変更

- 実機で `AdMob.then() is not implemented on android` を確認した。CapacitorのプラグインProxyをPromiseの解決値にすると、存在しないthenメソッドが呼ばれる。モジュールのオブジェクトで包んだまま非同期処理を通し、SDK初期化・広告準備・プライバシー操作を修正した。
- 広告の初回利用前に、未選択から始まる年齢層確認を追加。13歳未満、13〜15歳、16〜17歳、18歳以上の4択。キャンセルでき、生年月日は収集しない。年齢層は端末内だけに保存し、全員に子ども向け・同意年齢未満・GeneralのSDK設定を維持する。設定から変更できる。12言語とプライバシー表示を更新した。
- 広告の利用可否がログイン後に届いても、報酬ボタンを表示する。広告なし会員、未確認・期限切れ・別アカウントでは表示しない。
- 100マスチャレンジの開始前の会員問い合わせと広告待ちを外し、完了結果から次へ・再挑戦・戻るを選んだ後へ移動。連打を抑止し、同じ結果の広告は1回だけ試行する。広告失敗はゲーム進行を止めない。5題目・10題目の週替わり広告と、券を獲得する条件は別のまま。

## 確認できたこと

- 対象12ファイルの100テストと型検査が合格。Proxyのthen呼び出し、年齢選択キャンセル、会員切替、期限切れ、結果画面の連打、署名検証、報酬ルートと保存処理を含む。
- Pixel 10の別パッケージQAで、実NativeAdsラッパーを使用したGoogle公式テスト動画を2回表示。ヒント・対局券それぞれでSDKの視聴完了イベントを受け、通常のAndroid Backで閉じてearnedが返ることを確認した。テスト所要24.535秒。
- 同じ実機で年齢層が事前選択されず、選択前は続けるが無効、選択後に動画へ進むことを確認。合成アカウントの適格通知後に報酬UIが現れ、有料会員切替で消えることも確認した。
- 320×568のブラウザーでも日本語・タミル語のダイアログを確認。長い本文は縦スクロールし、横はみ出しはない。キャンセルと選択確定を操作した。これは実配布物全体の12言語検査の代替ではない。
- AdMobのQ-Gambitアプリは準備完了。世界向け同意メッセージを公開済み。既存の2報酬ユニットの署名付きサーバー通知先は保存・Googleテスト検証済み。Playの実際の対象年齢は6〜8、9〜12、13〜15、16〜17、18歳以上で、5歳以下は未選択。

実機の動画試験ではGoogleのデモ広告ユニットと合成アカウントを使用した。本番のアカウント、報酬インテント、券残高は作成・変更していない。ライブ広告の供給と実ユーザーの報酬入金が確認できたとは扱わない。
