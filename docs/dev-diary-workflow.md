# QUBE投稿・原稿の廃止

2026-10-07のユーザー指示により、過去・今後のQUBE投稿コーナーと手動投稿原稿を廃止した。以前の追記義務・過去投稿の保持義務は撤回済み。

- ログイン画面、アプリ内、公開Webに投稿コーナーを再追加しない。
- QUBE原稿を生成・追記・テキスト出力・再公開しない。追加／書き出しスクリプトと個別原稿は削除する。
- ヒント機能「QUBEに聞く」、既存QUBE画像、合法手探索、思考演出は維持する。
- 変更・検証・公開状況はチャットと開発／配信資料で報告する。
- Git履歴は書き換えない。Web反映とAndroid配布版の更新は別々に検証・報告する。
