# チュートリアル・週替わり問題の変更

対象: `S-Suzuki17/Q-Chess`、基点 `1e74cb4`。本番DB、Render、Cloudflare Pages、Google Playには未反映。

2026-10-20にユーザーから本番反映の実施承認とRenderの「My Workspace」の指定を受領。今回の公開対象はWeb・対戦サーバー・追加DBマイグレーション。Android配布と実広告の配信状態は別途記録する。

## プレイヤーの操作

- タイトルとロビーから「チュートリアル」を開く。チェスのルール16課題 → Q-Gambit独自のルール9課題の順で学ぶ。各課題に操作、説明、見本、やり直しを用意し、既存の課題IDとゲスト進捗を保持する。
- 登録アカウントの初回クリアごとに対局チケット1枚 → ヒントチケット1枚を交互に付与する。25課題すべてで対局13枚・ヒント12枚。課題を選び直しても、実際の初回クリア順で交互になる。見本の視聴と再クリアでは付与しない。
- ゲストもチュートリアルを練習できる。報酬にはログインと現行利用規約への同意が必要。ゲストの過去のクリアをログイン後の報酬へ自動変換しない。
- ロビーの「今週のチェス・プロブレム」は別の10題。通常のチェスの確定駒を使い、白から1手でチェックメイトする。順番に10題すべてクリアすると対局チケット1枚を付与する。
- 5題目・10題目の初回クリア応答で広告を要求する。広告なし会員・資格不明・広告取得不可の場合も進行でき、報酬を取り消さない。
- ヒントは自動着手しないことを明示。「この一手で変わること」で候補、捕獲、他の駒への影響、王手の変化を実際のエンジンから説明する。AIの探索理由や勝利を推測して表示しない。

## サーバーと保存

`GET /learning` と `POST /learning/complete` は既存の認証セッションを使用する。クライアントから報酬額、アカウントID、正解盤面、完了フラグを受け取らない。チュートリアルは全手順を、週替わり問題は保存された盤面でのメイトをサーバーで再検証する。

DBの一意制約とアカウント・財布のロックで、同時クリア・再送を直列化する。付与とクリア記録は同一トランザクション。削除中・制限中・規約未同意のアカウントを拒否し、削除時はクリア履歴もFKで連動して消去する。ブラウザーのDBロールには学習テーブルとRPCを開放しない。

未確認のクリア手順はアカウント別に端末保存し、再読込時に再送する。保存後に応答だけ失われても再付与しない。アカウント変更と古い応答を分離し、週が切り替わった後に前週の広告を新しい週の広告として再表示しない。

毎週火曜11:00 JSTから生成し、14:00 JSTに新しい10題を公開する。サーバー起動時と1分ごとの処理で、メンテナンス中に停止していても再起動時に追いつく。各問題はエンジンで唯一の1手メイトを確認し、過去の全公開局面と重複させない。10題まとめて保存し、公開済みの週は上書きしない。外部の問題集・ライセンス・生成APIには依存しない。

接続はWebSocketを先に試し、初期接続に失敗した場合はpollingへ切り替える。週次報告の接続障害の根本原因が特定・解消されたという主張はしない。報告にあった一部言語のThinking表示修正は既存コードにあり、12言語の回帰検証を追加した。

## 反映手順と戻し方

1. 本番適用前に既存マイグレーションの適用状況、バックアップ、現在のテーブル・RPCとの差異を読み取りで確認する。
2. `supabase/migrations/20261020111637_learning_rewards_and_weekly_problems.sql` をレビュー済みの対象DBへ適用する。新規4テーブル・3RPCのみを追加し、既存残高を一括変更しない。このファイルはCLIで採番している。
3. サーバーを更新し、`LEARNING_REWARDS_ENABLED=true` を設定する。既定は無効。起動処理で現在週の10題が揃い、認証した読み取りが成功することを確認する。
4. `docs/release.md` の対象別手順でフロントをビルド・反映する。広告は既存のAndroid AdMobプロバイダーと `NEXT_PUBLIC_NATIVE_LEARNING_INTERSTITIAL_ENABLED=true`、既存の広告設定・同意・資格確認が必要。
5. Web版は既存の `WEB_AD_RELEASE` が無効で、承認済みのゲーム用インタースティシャルプロバイダーも未接続。今回のWeb表示で実広告が配信されるとは扱わない。通常バナーを全画面広告に転用しない。

問題発生時は `LEARNING_REWARDS_ENABLED` を無効にして新規保存・公開を止め、必要に応じて直前のフロント／サーバーへ戻す。学習テーブルを削除せず、既に付与したチケットとクリア履歴を保持する。再有効化時の再試行も一意制約で重複を防ぐ。

週替わり問題の広告フラグは対局間広告とは独立させ、5・10題目の広告を有効にしても他の対局の広告や動画報酬を新たに有効にしない。
