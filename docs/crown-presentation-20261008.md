# Crown Circuit 表示・演出の改修

## 実装内容

- 挑戦／コレクションを切り替える画面構成。コレクションは盤面・駒・フレーム・演出・音楽のカテゴリごとにページ表示する。
- 城内背景は `PixelCastleBackdrop` が整数座標の SVG 図形で直接描画する。通常の縦画面・デスクトップでは画面内に収め、極端に短い画面や文字拡大時は内容パネルだけスクロールできる。
- 対戦相手の表示には既存 `QuantumPieceUI` を使用する。100 ステージ目だけキングの最終ボスとして表示する。CPU 強度・持ち時間・解放条件は既存の設定を使う。
- QUBE は原画を参照した座り姿の 2D SVG。待機、対局準備、勝利、励ましに応じて顔・頭・右腕・足などを動かす。通常状態の汗は非表示。動作は 3 秒以内で終わり、非表示時には停止する。
- 勝利演出は Three.js の立体的な王冠装飾、環、破片、星の軌跡、扇状の金属光で構成する。Crown の駒は対局時の材質・色と既存モデルを再利用する。描画失敗時は Canvas2D の構図へ戻る。
- アバターフレームは 5 系統・3 段階の造形を深め、プレビュー時だけ一度光が走る。通常の一覧では動かない。

## トップページの追加改善

- スクロールバーの配色と設定ボタン右側の余白を調整した。強制配色時のフォールバックを備える。
- Play の前に実際の Board3D / MatchLayout で描画したゲーム画面サンプルを表示する。局面は検証用の架空データで、実戦の記録ではない。元画像を切り抜かず、全体表示リンクと各言語の説明を付ける。
- サンプルの撮影元は統合元 2be9c0ef であり、今回の新 QUBE 表示を撮影した画像ではない。

## 保持する動作

既存の駒モデル、盤面／駒レンダラー、報酬 ID、所持判定、解放条件、進行データ、対局開始の許可・キャンセル処理は変更していない。閲覧・プレビューによる装備変更や報酬付与は行わない。

動きを減らす設定では静止画の構図・表情を使用する。効果音は既存の音量・ミュート設定に従う。素材の出典は各 `public/assets/*/PROVENANCE.md` に記載する。

## 統合元

`2be9c0efbe9858049c66c7bcfddbc003e89fc805` のヒント方針・QUBE 教学表示を保持して統合した。Crown の run/stage ID、保存ヒントの復元、無料練習とチケット制 Crown の区別を維持する。教学用の肖像だけは承認済みの静止 2D SVG にそろえた。

## ブラウザ確認用の入口

ローカルの架空データだけを使用し、外部通信を遮断する。

```
node scripts/qa/crown-showcase-server.mjs --build-only
node scripts/qa/crown-showcase-browser.mjs
node scripts/qa/crown-browser.mjs
node scripts/qa/check-lobby-browser.mjs
```

既にインストールされた Chromium を指定する場合は `QG_TEST_CHROMIUM` を使う。ショーケースの結果には、WebGL が実際に使われたか、コンテキスト喪失テストを実行できたかを残す。フォールバックのみの成功を立体演出の描画確認として扱わない。

ショーケースは本番アカウント、実際の対局完了、決済、オンラインの報酬保存を検証するものではない。
