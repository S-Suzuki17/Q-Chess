# Codex / Antigravity
共通ルールはルートの AGENTS.md が正本。Antigravity の .agents/rules/project.md は参照だけを持つ。
スキルは .agents/skills/ の同じ2つを共有する。Claude Code用の追加設定は作らない。
既存 CLAUDE.md は Next.js の生成互換ファイルとして残す。独自ルールは追加しない。

## 担当
- 通常の実装と関連テストは作業を受けたエージェントが完了する。
- 複雑な変更では、必要に応じて他方が仕様の抜け・反例・差分をレビューする。毎回の二重レビューは不要。
- 同じ作業ツリーで同時編集しない。同時作業は別ブランチ・別worktreeに分ける。
- 公開担当は1つにする。Web公開とAndroid成果物作成は別の完了条件。

## 引き継ぎ
目的、対象ブランチ/コミット、変更ファイル、実施した検証、未解決事項だけを渡す。
未コミット変更がある場合は、その所在と所有者も明記する。会話全文はコピーしない。

## 資料の維持
AGENTS.mdに作業手順を増やさず、必要なdocsへ条件付きで案内する。
新しいスキルは同じ手順が繰り返され、既存2つでは扱えないときに検討する。
プラグインキャッシュ内のSKILL.mdは編集しない。
