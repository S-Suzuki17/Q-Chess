# アカウント装飾・3D階級バッジ仕様書

更新: 2026-09-18 / 実装 v1。AAA級は目標であり、品質保証や検証結果を意味しない。

## 1. 概要
本仕様書は、Q-Gambitにおけるプレイヤーのプロフィール（アカウント）装飾の実装契約を定義する。公開・AAB作成は別作業とし、既存のプロフィール画像、報酬、セーブ、対局時計を変更しない。
プレイヤーのアバター画像の視認性を損なわず、かつ「AAA級」のプレミアム感を提供するため、以下の2軸の報酬システムを実装する。

1. **ソロプレイやり込み報酬**: 外枠（フレーム）および背面オーラ
2. **対人レーティング階級**: プロフィール詳細のアバター右下に配置する3Dバッジ。持ち時間別の現在レートから自動算出し、手動装備や永久獲得とは区別する。

### 操作フロー

- 設定 → アカウント → 「階級バッジ」。初期表示は10分の現在レート。10分／3分／1手10秒を切り替えられる。
- 6種すべてを無料で鑑賞できる。「プレビューのみ」と明示し、上部の実階級・装備・レート・セーブは変えない。「自分の階級に戻す」で復帰。
- CPU／オンライン対局開始演出と対局バーには、対局の持ち時間に対応するレートの軽量バッジを表示する。CPU・ゲスト・取得不能のレートには架空の階級を与えない。
- 対局中・小型アイコン・一覧のバッジは、同じ意匠のSVGを使う。プロフィール詳細のみ実際のWebGL 3Dにし、アイコンごとのCanvas増殖を避ける。

## 2. ソロプレイ報酬：外枠と背面オーラ
ユーザーが設定したカスタム写真（アバター）を決して隠さず、かつ豪華さを演出するため、「写真の背面（Z軸奥）」と「境界線（エッジ）」のみにエフェクトを適用する。

### デザイン原則
- **背面オーラ**: 写真より後ろの静かな色付き後光。既存15種のフレームを保持し、顔の中心を覆わない。常時パーティクルは使わない。
- **境界線装飾**: 既存のSVGフレームを継続。小型UIにWebGL流体描画を追加しない。3D金属反射はバッジ詳細で表現する。
- **視差と動的ライティング**: バッジ詳細のホバー・キーボードフォーカス中のみ、小さなティルトと上位リングの回転。ジャイロ権限は要求しない。端末の「動きを減らす」、ユーザーの静止設定、非表示タブでは静止する。

---

## 3. レーティング報酬：階級バッジ（3Dエンブレム）
対戦モードの現在レートを示すアーティファクト。写真の右下外側に配置し、中央を覆わない。大きな詳細で形を鑑賞し、小型表示ではシルエットと色で識別する。
チェスの駒（ポーン〜キング）をモチーフとし、階級が上がるごとに材質とエフェクトが劇的に進化する。

### 階級別デザイン仕様

### レート境界（初期設定）

既存のMaster到達値2400を維持し、旧Diamond帯をPlatinum／Diamondに分ける。レート計算式・初期レート・マッチングは変更しない。境界の正本は `src/config/profileBadges.ts`。値を切り上げて判定しない。

| 現在レート | バッジ |
| --- | --- |
| 1200未満 | 未昇級・バッジなし |
| 1200–1499 | ポーン／ブロンズ |
| 1500–1799 | ナイト／シルバー |
| 1800–2099 | ビショップ／ゴールド |
| 2100–2249 | ルーク／プラチナ |
| 2250–2399 | クイーン／ダイヤ |
| 2400以上 | キング／マスター |

欠損・非数・負値は「レート未取得」。プロフィールは本人IDの公開プロフィール行だけを使い、最高レートの自動選択や代替の1500／2000は使わない。クライアント表示はアクセス権の証明ではなく、新しい認証・権限付与には流用しない。

#### ♟️ 1. ポーン級（ブロンズ帯）- 「アイアン・シールド」
* **ベース形状**: 無骨な鉄（アイアン）で鋳造された盾型のバッジ。
* **駒モチーフ**: 中央に深く刻み込まれたポーンのシルエット。
* **実装**: 面取りした盾、暗い鋳鉄のインセット、立体ポーン、控えめな金属反射。傾きは詳細のポインター／フォーカス操作のみ。

#### ♞ 2. ナイト級（シルバー帯）- 「ウインド・クレスト」
* **ベース形状**: 左右に馬の鬣（たてがみ）や風を模した鋭い装飾が伸びる純銀の紋章。
* **駒モチーフ**: バッジから少し飛び出すように彫刻された3Dのナイトの頭部。
* **実装**: 左右3本ずつの銀のウイング、厚みのあるナイト彫刻、寒色の反射。周期的な点滅はしない。

#### ♝ 3. ビショップ級（ゴールド帯）- 「ホーリー・クリスタル」
* **ベース形状**: 黄金の装飾に囲まれた透明な丸いクリスタルレンズ（ガラスドーム）。
* **駒モチーフ**: レンズの奥深くに封入され、黄金に輝くビショップ。
* **実装**: 金の円形台座と縁、ビショップ彫刻、透過するガラスドーム。透過描画は詳細の1個のみ。発光の脈動は使わない。

#### ♜ 4. ルーク級（プラチナ帯）- 「オブシディアン・フォートレス」
* **ベース形状**: 城壁の銃眼を模した、重い黒曜石（オブシディアン）とタングステンのバッジ。
* **駒モチーフ**: 中央のルークの彫刻には亀裂が入り、内部の高密度エネルギーが覗く。
* **実装**: 銃眼のある盾、角張ったルーク、黒いインセットと細い赤銅色の亀裂。常時の火の粉は省略し、対局への視覚的干渉を避ける。

#### ♛ 5. クイーン級（ダイヤ帯）- 「アストラル・コア」
* **ベース形状**: 固定枠を持たず、中央コアの周囲を「プラチナのリング」が2〜3重に空中で公転する。
* **駒モチーフ**: カットの美しいアメジスト（紫水晶）で削り出されたクイーンの王冠が浮遊。
* **実装**: 紫水晶風の多面体王冠と2本のプラチナリング。操作中のみ低速回転し、画面全体の屈折・光跡は使わない。

#### ♚ 6. キング級（マスター帯・最上位層）- 「絶対王者の戴冠（Apex Crown）」
* **ベース形状**: 右下の空間に、ホログラフィックに輝く「立体的なキングのチェス駒」そのものが直接鎮座する。枠組みの概念を破壊。
* **駒モチーフ**: 純金とダイヤモンドで構成されたキング。背後に後光（サンバースト）を展開。
* **実装**: 金のキングと小さな透過宝石、12本のサンバースト。ホバー音・フラッシュ・スターダストは実装しない。ミュート設定や光過敏への配慮を優先する。

## 4. 技術・受入条件

- `ProfileCosmetics.tsx` はアカウントを開いた時だけ読み込む。`RankBadgeScene.tsx` は別の遅延ロード。1つの詳細につきCanvasは1つ、写真はDOMのまま保持する。
- モデルはコードによる押し出し・回転体・面取り形状。外部3Dモデルや画像の通信は追加しない。金属反射用の既存 `StudioReflections` を再利用し、背景・3Dルームは作らない。
- R3F所有のgeometry/materialはアンマウント時に破棄、環境マップも既存クリーンアップに従う。DPR上限1.5はバッジCanvasだけに適用し、盤面の描画解像度は変更しない。
- 静止時はdemand描画。アニメーションは操作中・可視タブ・reduced-motion無効の時だけ。カメラの手動回転・ズームは付けない。タッチの縦スクロールを妨げない。
- 読み込み中・WebGL初期化失敗・context loss時は同じ階級のSVGを表示。写真や名前まで消失させず、WebGLエラーを無限再試行しない。
- 12言語の階級名・操作文言・取得不能状態を用意。全プレビューボタンに名前と最低レート、選択状態を付け、キーボードでも操作可能にする。
- 単体検証: 全境界±小数、欠損/非数、12言語、写真保持、現在階級とプレビュー分離、小型表示のCanvas不使用。
- ブラウザー検証: PCと360px縦画面、全6種切替、3種類の持ち時間、セーブ不変、静止設定、WebGL context loss後SVG、アカウントを閉じた後Canvas破棄。接続Android端末がない限り実機確認済みとはしない。
